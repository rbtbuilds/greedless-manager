# Greedless Manager 0.1.0 - source preview

Free, GPL-2.0-only window management for Apple Silicon Macs. This is a small, explicitly credited fork of [OmniWM](https://github.com/OmniNull/OmniWM) v0.7.6. OmniNull and the upstream contributors built the window-management engine.

## Get started

This release provides **source code**, not a notarized installer. Build locally with full Xcode 27+, Swift 6.4+, and a compatible macOS version. A paid signing membership is not required for the local ad-hoc build.

- [Build and first launch](https://github.com/rbtbuilds/greedless-manager/blob/greedless-v0.1.0/docs/BUILD.md)
- [Copy-paste setup task for your coding agent](https://github.com/rbtbuilds/greedless-manager/blob/greedless-v0.1.0/docs/AGENT_SETUP.md)
- [Troubleshooting](https://github.com/rbtbuilds/greedless-manager/blob/greedless-v0.1.0/docs/TROUBLESHOOTING.md)

Clone the fixed release:

```sh
git clone --branch greedless-v0.1.0 --single-branch https://github.com/rbtbuilds/greedless-manager.git
cd greedless-manager
make setup
make doctor
make app
```

Read the build guide before launching: Accessibility and Input Monitoring are required, Screen Recording is optional, and starting the app can rearrange open windows.

## What changed from upstream

- Greedless Manager app identity, original icon, isolated configuration/state, and the bundled `greedlessctl` command.
- Upstream scrolling and Dwindle layouts, workspace management, settings, and CLI retained.
- Ad-hoc local packaging, disabled upstream update checks, and reports that copy locally for review.
- Settings reopen/redirect fix, fork identity tests, and safeguards against running the old upstream installer.
- Build, agent setup, troubleshooting, contribution, provenance, and verification documentation.
- Separate build/test workflow; inherited publishing automation archived.

## Verification and limits

Local checks: **5,124 Swift tests passed, 34 skipped, zero failures; 113 Python tooling tests passed**. Formatting, lint, strict compilation, localization checks, and package signature verification passed. Lint reports three existing type-length warnings.

Live disposable-window checks covered focus, column scrolling/reordering/resizing, floating, closing, Settings, and quit/relaunch. Physical gestures, VoiceOver, display hot-plugging, sleep/wake, capture previews, and exhaustive multi-monitor behavior were not tested. See the [verification record](https://github.com/rbtbuilds/greedless-manager/blob/greedless-v0.1.0/docs/verification.md).

This is an early fork. Updates are manual, and rebuilt ad-hoc apps can require renewing their macOS permission entries. The source retains upstream copyright and GPL notices; see [fork provenance](https://github.com/rbtbuilds/greedless-manager/blob/greedless-v0.1.0/FORK.md).
