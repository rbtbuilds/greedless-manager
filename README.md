# Greedless Manager

Greedless Manager is a free, open-source tiling window manager for Apple Silicon Macs running macOS 26 or later. It is a fork of [OmniWM by OmniNull and its contributors](https://github.com/OmniNull/OmniWM), based on upstream v0.7.6 at commit [`3c0783954604eaa9110d0bdb61fa29f953e738ee`](https://github.com/OmniNull/OmniWM/commit/3c0783954604eaa9110d0bdb61fa29f953e738ee). The fork retains OmniWM's window-management features, including scrolling and binary-space-partition layouts, workspaces, Overview, and its local command interface.

This is an early fork, version 0.1.0 (build 1), with a verified local app build. The public source is hosted at [rbtbuilds/greedless-manager](https://github.com/rbtbuilds/greedless-manager). The initial release is source-only. Local builds are signed ad hoc; they are not notarized.

The full Swift suite completed with 5,124 tests passed, 34 skipped, and no failures. Desktop checks covered scrolling columns, focus, resizing, reordering, floating, closing, settings, and quit/relaunch. See [verification status](docs/verification.md) for evidence and coverage limits. Automatic update checks are disabled, and the report composer copies reports locally instead of opening upstream issues.

## Build and run locally

The app runs on macOS 26 or later on arm64. Building requires an Apple Silicon Mac, full Xcode 27+, Swift 6.4+, and a macOS version supported by that Xcode (26.6+ for Xcode 27/27.1). See the [complete build guide](docs/BUILD.md) for prerequisites and first launch.

**Building with an AI coding agent?** Copy the task from [the agent setup guide](docs/AGENT_SETUP.md). It includes preflight checks, compilation, verification, and safe desktop testing.

Quick start after Xcode setup:

```sh
git clone --branch greedless --single-branch https://github.com/rbtbuilds/greedless-manager.git
cd greedless-manager
make setup
make doctor
make app
# Save your work and quit other tiling managers before launching.
open "dist/Greedless Manager.app"
```

`make app` creates `dist/Greedless Manager.app` and signs it ad hoc. `make run` rebuilds that app and opens it from `dist`; it does not quit any running window manager. Quit an older Greedless Manager instance yourself before opening a rebuilt copy. The legacy `make dev-install`, `make use-dev`, and `make use-release` workflow is not used for this fork; `make dev-install` is an alias for `make run`. Direct use of `Scripts/omniwm-dev.sh` is disabled.

Accessibility and Input Monitoring are required. Screen Recording is optional; choose **Continue Without Screen Recording** to use window management without capture-based previews. Rebuilding an ad-hoc signed app can invalidate its existing macOS permission entries. If access remains denied after rebuilding, remove and add the current app in the corresponding Privacy & Security lists, then quit and reopen it.

The bundled command-line executable is `dist/Greedless Manager.app/Contents/MacOS/greedlessctl`. It is not installed onto your `PATH` automatically. The app's internal executable and some Swift modules still use `OmniWM` names; these are implementation names, not the fork's app identity.

Greedless Manager stores its editable settings at `${XDG_CONFIG_HOME:-$HOME/.config}/greedless-manager/settings.toml` and state at `${XDG_STATE_HOME:-$HOME/.local/state}/greedless-manager`. Relative XDG base paths are ignored in favor of the defaults. It uses its own bundle identifier, `org.greedless.manager`, so it does not take over OmniWM's app identity.
