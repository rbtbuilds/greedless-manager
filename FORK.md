# Fork provenance

Greedless Manager is derived from [OmniNull/OmniWM](https://github.com/OmniNull/OmniWM), upstream release v0.7.6, commit `3c0783954604eaa9110d0bdb61fa29f953e738ee`. Its original README is preserved verbatim in [docs/upstream/README.md](docs/upstream/README.md). The upstream contributors and copyright holders retain credit for their work; the source notices and [GPL-2.0-only license](LICENSE) remain in place.

The initial fork changes the user-facing app identity, local configuration and state locations, command name, and local packaging defaults. It reuses the upstream window-management implementation and features, including Niri-style scrolling containers, Dwindle layouts, workspace and display management, Overview, menus and settings, and the local CLI/IPC architecture. No claim of independent authorship is made for that code.

`OmniWM` remains the internal Swift app executable and appears in module, bundle, resource, test, entitlement, and some script names. Those names are retained to keep the fork small and preserve build compatibility. The packaged app is `Greedless Manager.app` with bundle identifier `org.greedless.manager`; its bundled CLI is `greedlessctl`. Greedless Manager starts at version 0.1.0 (build 1), independently of upstream's version.

The inherited upstream workflows, funding configuration, and DigitalOcean deployment file are archived under `docs/upstream/`. The original website and release scripts target OmniWM and are not Greedless Manager publishing instructions. This fork uses a separate read-only build/test workflow, its `greedless` branch, and `greedless-v<VERSION>` release tags. Local `make app` and `make run` use ad-hoc signing. Distribution signing and notarization require a separately supplied Greedless Manager signing identity and notarization profile; no upstream credentials are inherited.

The direct upstream development installer is preserved at [docs/upstream/Scripts/omniwm-dev.sh](docs/upstream/Scripts/omniwm-dev.sh). Its active path fails before packaging, quitting processes, or replacing an app because that workflow still targets OmniWM's installed app and identity.

The fork's green three-column app icon, monochrome status template, and white launch lockup are original artwork generated by `Scripts/generate-greedless-brand.swift`. The generator writes `Resources/GreedlessIcon.icns` and the two `Greedless*.pdf` resources. Upstream OmniWM artwork is preserved in place for provenance and is not packaged as the fork's icon or used for its status and launch marks.
